# YAMP (Yet-Another-Music-Player)

Took Inspo from [foobar2000](https://www.foobar2000.org/) and [Spotify](https://www.spotify.com/)

**Python Version Used: [3.13.3](https://www.python.org/downloads/release/python-3133/)**

README file is currently updated per version
<details>
<summary>Features:</summary>

* Free

* Read only .ogg, .opus, .oga, .flac, .mp3, .flac, .ogg, .oga, .opus, .wav, .m4a, .mp4, .aac, .wma, .aiff, .aif, .m3u, .m3u8 files

* Show embedded images/authors/titles

* Read .lrc with timed/plain text lyrics

* Romanize and Translate Japanese

* Show in Windows Media Manager

* Stuff that most music players have

* Theme Editing (must goto %APPDATA%\errorC003C004\Music Player\{preset}\preset.json to change theme)

* Audio Normalization

</details>
